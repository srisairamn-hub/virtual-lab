# THERMO LAB 360 🧪
### Interactive Thermodynamics Virtual Learning Lab

THERMO LAB 360 is an interactive educational web application built with [Streamlit](https://streamlit.io/) designed to help beginner college students master core concepts in engineering and chemical thermodynamics through digital simulations and calculators.

---

## 🚀 Features

- **👤 Student Details & Registration:** Persistent academic session tracking (Name, Register Number, Department, Course).
- **📊 Student Dashboard:** Real-time metrics overview tracking syllabus progress, quiz scores, and completed modules.
- **🔬 Gas Expansion Simulator:** Live interactive piston chamber modeling using the Ideal Gas Law ($PV = nRT$) with dynamic isothermal plots.
- **⚡ Gibbs Free Energy Calculator:** Automated $\Delta G = \Delta H - T\Delta S$ computation determining reaction spontaneity and equilibrium states.
- **📚 Syllabus Modules:** Core coverage of basic thermodynamics, laws of thermodynamics, entropy, free energy, and electrochemistry.
